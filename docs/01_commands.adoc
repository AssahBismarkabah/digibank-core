= Digi Bank Commands

== Workshop 4 Microservices Quick Start

Use these commands from the repository root while on the `main` branch.

[source,shell]
----
make build        # Compile and test all microservices
make image-build  # Build the Docker images
make up           # Start the complete Compose stack
make smoke        # Verify the gateway and platform endpoints
----

Use the following commands for the remaining lifecycle and validation
operations:

[source,shell]
----
make status          # Show container status
make logs            # Follow service logs
make restart         # Recreate the stack
make validate-stack  # Confirm every expected container is running
make newman-scan     # Replay the API security collection
make zap-scan        # Run the OWASP ZAP baseline scan
make down            # Stop the containers
make clean           # Stop containers and remove database volumes
----

The detailed microservice architecture, deliverables, and design decisions are
documented in `docs/07_microservice_architecture.adoc` and the service-specific
notes in `digibank-microservices/README.adoc`.

== Branches Used In The Workshop

* `main` -- Spring Boot microservices implementation for Workshop 4.
* `monolith-implementation` -- Spring Boot modular monolith implementation for
  Workshop 3 and migration comparison.
* `legacy/jakarta-ee` -- original Jakarta EE implementation used as the
  reference system.

The remaining sections describe the earlier modular-monolith implementation.
Run those commands only after checking out `monolith-implementation` or
`legacy/jakarta-ee` as appropriate.

== Build And Test

[source,shell]
----
cd digibank-parent

make build       # Compile, test, and package the project
make test        # Run the Maven test suite
make clean       # Remove Maven build artifacts
----

== Run Locally With Embedded Tomcat

[source,shell]
----
cd digibank-parent

make up          # Start PostgreSQL and Spring Boot
make smoke-test  # Run the smoke tests
make down        # Stop the containers
----

The application is available at `http://localhost:8080/`.

== Run With WildFly

[source,shell]
----
cd digibank-parent

make up-wildfly  # Start PostgreSQL and deploy the WAR to WildFly
make smoke-test  # Run the smoke tests
make down        # Stop the containers
----

The application is available at `http://localhost:8080/digibank-app/`.

== Full Verification

This command builds the project, starts the development stack, runs the smoke
tests, and stops the containers:

[source,shell]
----
cd digibank-parent
make verify
----

== Container And Log Commands

[source,shell]
----
cd digibank-parent

make up-foreground  # Start development mode and show logs
make logs           # Follow all container logs
make logs-app       # Follow application logs
make logs-db        # Follow PostgreSQL logs
make down-volumes   # Stop containers and remove the database volume
----

Use `make down-volumes` when a clean database is required. It deletes the
local PostgreSQL volume and all seeded data.

== Security Validation

[source,shell]
----
cd digibank-parent

make zap-scan       # Run the OWASP ZAP baseline scan
make zap-report     # Open the latest ZAP report
----

Run `make help` to display all available Makefile targets.
