= Digi Bank


Digi Bank is a reference implementation of a core banking platform built as a
modular monolith using Jakarta EE 10. It demonstrates modern Jakarta EE
patterns: DTOs, Bean Validation, ExceptionMappers, BigDecimal for monetary
values, CDI testing with Weld, and Docker Compose deployment.

The project is organized into 8 Maven modules with strong module boundaries,
designed to be split into microservices later if needed.

This is an educational project for the Cloud Computing Professional License
course (June 2026). It serves as the reference Jakarta EE implementation
before migrating to Spring Boot.

== To start using Digi Bank

See the link:docs/getting-started.adoc[Getting Started guide] for

== To start developing Digi Bank

The link:docs/getting-started.adoc[Getting Started guide] covers everything
from cloning the repository to running the automated smoke tests.

If you want to run Digi Bank right away there are two options:

##### You have Docker installed (recommended)

[source,shell]
----
git clone <repo-url>
cd digibank-parent
make verify
----

##### You have Java 17+ and Maven 3.9+ installed

[source,shell]
----
git clone <repo-url>
cd digibank-parent
mvn clean package -DskipTests
docker compose up --build -d
./scripts/smoke-test.sh
----

For the full story, head over to the link:docs/getting-started.adoc[Getting Started guide].
