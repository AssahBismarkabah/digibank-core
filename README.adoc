= Digi Bank Microservices

This branch contains the standalone Spring Boot microservices implementation
for Workshop 4. The previous monolith implementation is available on `main`.

== Quick Start

[source,shell]
----
make build
make image-build
make up
make smoke
----

Use `make status`, `make logs`, `make restart`, `make down`, and `make clean`
for the remaining lifecycle operations. Detailed commands are documented in
`digibank-microservices/README.adoc`.

This is an educational project for the Cloud Computing Professional License
course (June 2026), focused on service boundaries, independent persistence,
inter-service calls, container orchestration, and CI validation.
