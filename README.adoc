= Digi Bank MSA Impl

This branch contains the standalone Spring Boot microservices implementation
for Workshop 4.

This is an educational project for the Cloud Computing Professional License
course (June 2026), focused on service boundaries, independent persistence,
inter-service calls, container orchestration, and CI validation.

== Project Status

This branch is the microservice implementation on `main`.

The Spring Boot modular monolith is preserved on `monolith-implementation` for
Workshop 3 comparison. The original Jakarta EE implementation is preserved on
`legacy/jakarta-ee` as the reference implementation.
