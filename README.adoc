= Digi Bank

----

Digi Bank is a reference implementation of a core banking platform built as a
**modular monolith** using Jakarta EE 10. It demonstrates modern Jakarta EE
patterns: DTOs, Bean Validation, ExceptionMappers, BigDecimal for monetary
values, CDI testing with Weld, and Docker Compose deployment.

The project is organized into 8 Maven modules with strong module boundaries,
designed to be split into microservices later if needed.

This is an educational project for the Cloud Computing Professional License
course (June 2026). It serves as the reference Jakarta EE implementation
before migrating to Spring Boot.

----

== Quick Start

=== Prerequisites

* link:https://docs.docker.com/engine/install/[Docker Desktop] or Docker Engine 24+
* link:https://adoptium.net/temurin/releases/?version=17[Java 17+ JDK] (only if building locally)
* link:https://maven.apache.org/download.cgi[Apache Maven 3.9+] (only if building locally)

=== One-Command Deploy

[source,shell]
----
git clone <repo-url>
cd digibank-parent
make verify
----

This builds the project, starts PostgreSQL and WildFly via Docker Compose,
waits for readiness, and runs 23 automated smoke tests.

=== Step by Step

[source,shell]
----
# Build the project
mvn clean package -DskipTests

# Start services
docker compose up --build -d

# Run smoke tests
./scripts/smoke-test.sh

# Stop everything
docker compose down
----
